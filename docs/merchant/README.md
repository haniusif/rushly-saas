# Merchant Dashboard — User Guide

Welcome to Rushly. This guide walks you through everything you can do in the
merchant dashboard: creating and tracking shipments, managing your shops,
finances and reports, and connecting your own systems via the API and webhooks.

## Getting started

1. **Sign in** at your Rushly dashboard URL with the credentials you were given.
2. Use the **left sidebar** to move between sections, and the **top bar** for
   quick actions:
   - **New shipment** — create a shipment from anywhere.
   - **Profile / change password**, **notifications**, **language**, and
     **light/dark theme**.
