# Reports

See how your deliveries are performing.

## Total Summary

A high-level **summary** of your shipments and their outcomes over a period —
good for a quick health check (totals delivered, returned, etc.).

## Parcel Reports (Shipment status reports)

A detailed, filterable report of shipments by:

- **date range**,
- **status** (multi-select),
- **hub / branch**.

Results group shipments by status so you can spot bottlenecks. You can
**export** the filtered set and **print** a report-friendly view for operations
or audits.

## Tips

- Use date + status filters together to answer questions like "how many were
  delivered last week vs. returned?"
- For programmatic reporting, pull the same data via the Merchant API
  (`GET /v1/shipments` with filters).
